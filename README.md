# EventHub – Event Management System

EventHub is a web-based event management application developed using ASP.NET Core and C#.

## Project Description

EventHub allows users to discover events, view event details, register for events, and manage event-related activities.

Event organizers can create and manage events and view registered attendees.

## Technology Stack

- C#
- ASP.NET Core MVC
- .NET 8
- Entity Framework Core
- Relational Database
- HTML/CSS/JavaScript

## Core Features

- User Registration and Login
- User Roles and Authorization
- Create and Manage Events
- Browse, Search and Filter Events
- View Event Details
- Event Registration
- Attendee Management
- User and Organizer Dashboard
